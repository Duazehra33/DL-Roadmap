# Deep Learning – Week 01
## Introduction to Deep Learning & Basic Neural Networks

This repository contains the theoretical and practical learning materials for Week 1 of Deep Learning, focusing on the foundations of Neural Networks, Artificial Neural Networks (ANN), and Multi-Layer Perceptrons (MLP).

The repository includes one theoretical PDF and two practical Jupyter Notebooks covering the fundamentals of neural networks and their implementation using PyTorch.

## Contents

### 1. `Introduction to Deep Learning Week 1.pdf`
**Theory & Conceptual Understanding**

Covers the fundamental concepts of Deep Learning and Neural Networks, including:

- Introduction to Deep Learning and Neural Networks.
- Artificial Neural Networks (ANN) and MLP architecture.
- Neurons, weights, and biases.
- Input, hidden, and output layers.
- Activation functions: ReLU, Sigmoid, and Tanh.
- Forward propagation and backpropagation.
- Loss functions: MSE and Cross-Entropy.
- Optimization algorithms: SGD and Adam.
- Overfitting, underfitting, and regularization.

### 2. `basicNN.ipynb`
**Basic Neural Network Implementation**

Focuses on understanding the fundamental structure and working of a basic fully connected Neural Network.

- Understanding neural network architecture.
- Working with neurons, weights, and biases.
- Understanding input, hidden, and output layers.
- Exploring forward propagation.
- Understanding the mathematical operations behind neural networks.
- Learning the basic neural network training workflow.

### 3. `UsingPyTorch.ipynb`
**Neural Network Implementation Using PyTorch**

Demonstrates how to build and work with neural networks using the PyTorch deep learning framework.

- Introduction to PyTorch and tensors.
- Building neural network models.
- Defining layers using PyTorch.
- Implementing forward propagation.
- Calculating loss using loss functions.
- Applying backpropagation and gradient calculation.
- Optimizing model parameters using optimizers.
- Understanding the neural network training process.

##  How to Run

Install the required libraries:


pip install torch numpy pandas matplotlib scikit-learn jupyter


Launch Jupyter Notebook:


jupyter notebook


Open and execute the notebooks individually:

1. `basicNN.ipynb`
2. `UsingPyTorch.ipynb`

Alternatively, upload the notebooks to Google Colab.

##  Learning Outcomes

- Understand the foundations of Deep Learning and Neural Networks.
- Learn the architecture and mathematical working of MLP.
- Understand neurons, weights, biases, and activation functions.
- Explore forward propagation and backpropagation.
- Understand loss functions and optimization algorithms.
- Implement basic neural networks using PyTorch.
- Understand the complete neural network training workflow.
